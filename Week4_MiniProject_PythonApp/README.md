# Week 4: Mini Project – Python Application

## Goal
Apply everything you’ve learned (functions, lists, dictionaries, file handling, error handling) in a real-world mini project.

---

## Project Ideas
1. **To-Do List CLI App** – Add, view, delete tasks saved in a file.
2. **Quiz Game** – Multiple-choice questions with scoring.
3. **Weather Info App** – Fetch weather using an API.
4. **File Organizer** – Automatically organize files in folders.

---

## Steps to Follow
1. Pick a project idea.
2. Break it into smaller parts:
   - Input → Logic → Output → Save Data
3. Use **functions** to organize code.
4. Test and improve.
