# Week 6: APIs and JSON

## Goal
Work with real-world data from the internet using APIs and process it with JSON.

---

## Steps to Follow
1. Learn what **APIs** are (Application Programming Interface).  
2. Use `requests` to fetch data from an API.  
3. Use `json` to process the data.  

---

## Task Ideas
- Build a **Weather App** using a weather API.  
- Build a **News App** using a news API.
