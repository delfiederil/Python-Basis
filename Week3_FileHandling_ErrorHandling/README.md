# Week 3: File Handling & Error Handling

## Goal
Learn how to read/write data to files and handle errors smoothly.

---

## Steps to Follow

1. Learn how to open, read, and write `.txt` or `.csv` files in Python.
2. Understand `try`, `except`, and `finally` blocks for error handling.
3. Task Example:
   - Build a contact book or a mini journal that saves to a file.

---

## Example Code Files

### 1. file_read_write.py
Basic operations to read and write files.

### 2. context_manager_demo.py
Use `with` statement for safer file handling.

### 3. try_except_demo.py
Learn error handling using `try-except-finally`.

### 4. contact_book.py
Mini project: add, list, and search contacts saved in a file.
