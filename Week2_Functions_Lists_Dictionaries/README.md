# Week 2: Functions, Lists & Dictionaries

## Goal
Learn how to organize code and store data efficiently.

---

## Steps to Follow
1. Learn how to define and call functions.
2. Understand:
   - **Lists**: storing items in order
   - **Dictionaries**: storing data in key-value pairs
3. Task Example:
   - Make a program that stores and displays student scores
   - Add a function to calculate average score

---

## Example Code Files

### 1. student_scores.py
A program that stores student names with their marks in a dictionary and displays them.

### 2. average_function.py
A function to calculate the average of student scores.

### 3. list_dictionary_demo.py
Practice file to learn how lists and dictionaries work.
