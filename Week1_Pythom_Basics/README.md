# Week 1: Python Basics & Control Structures  

📚 This week is all about learning the **core building blocks of Python**.  
🎯 The main goal is to understand how Python handles variables, data types, operators, and basic control structures like `if-else` and loops.  

### ✅ What I did in Week 1  
- 💻 Installed Python from [python.org](https://www.python.org) (or used Google Colab).  
- 📖 Learned about:  
  - 🔤 Variables and data types (`int`, `float`, `string`, `boolean`)  
  - ➕ Operators (`+`, `-`, `*`, `/`, `%`, `//`, `**`)  
  - 🔀 `if-else` statements and loops (`for`, `while`)  

### 🛠️ Practice Programs  
I wrote three simple programs to apply what I learned:  
1. 🧮 **Calculator** → performs basic arithmetic.  
2. 🔢 **Even/Odd Checker** → tells whether a number is even or odd.  
3. ✖️ **Multiplication Table Generator** → prints the table of any number.  

💡 These exercises helped me practice coding, get comfortable with syntax, and understand how logic works in Python.
